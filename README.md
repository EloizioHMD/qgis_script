# 🗺️ QGIS Scripts (`qgis_script`)

Repositório pessoal com scripts em Python (`PyQGIS`) para automação de tarefas e rotinas de geoprocessamento no QGIS.

---

## 🚀 Como Executar no QGIS

1. Abra o QGIS com o seu projeto/camadas carregadas.
2. Abra o Console Python: **Plugins** $\rightarrow$ **Console do Python** *(ou `Ctrl + Alt + P`)*.
3. Clique no ícone **Mostrar Editor** 📝 (ícone de caderno com lápis) para abrir o painel de texto.
4. Copie o código do script desejado, cole no Editor e clique no botão **Executar Script** ▶️ *(ou `Ctrl + R`)*.
